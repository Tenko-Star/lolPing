# lolPing Lite

[English](README.md) | 简体中文

lolPing 的精简版，一个只有几百 KB 的小玩具：按 **Alt + ?**，局域网里所有人的屏幕上随机出现一个英雄联盟的“？”（敌人消失）信号，带原版音效。没有设置页，只有托盘图标。

## 使用

1. 运行 `lolping-lite.exe`。没有窗口，任务栏右下角的托盘里会出现图标。第一次运行时 Windows 防火墙会询问是否允许访问网络，请允许“专用网络”。
2. 按 **Alt + ?**，也就是 Alt 加右 Shift 左边那个 `/?` 键。按的是键位，不受键盘布局影响，小键盘的 `/` 不算。这个按键仍会传给当前程序，lolPing Lite 只是旁听。
3. 同一局域网里运行着 lolPing Lite 的人都会看到。

- 限流：每人最快 100 ms 发一次，任意 5 秒内最多 5 次。按住不放也一样。
- 每个“？”的动画和存在时间（3.2 秒）与原版一致。
- 落点：在收到的那台机器上随机产生，落在鼠标所在的显示器上。分布是一个贴合屏幕比例的实心椭圆，一圈最密，中间稍稀（约为最密处的 30%），越靠边越少，边缘 5% 以内不会出现。
- 连发：同一个人连续发（距上一个不到 3.2 秒），后面的“？”落在这一串第一个的附近。

## 托盘菜单

右键（或左键）点击托盘图标：

- **本机是主节点 · 在线 N 人**，或者 **在线 N 人**：只显示，不能点。
- **停止接收**：不再显示别人的“？”，托盘图标变灰。如果本机是主节点，仍然照常转发。
- **显示自己发出的“？”**：默认关闭，自己按的时候自己屏幕上不出现。
- **开机自启**
- **退出**

开关的状态保存在注册表 `HKCU\Software\lolPing Lite`。

## 网络

全程使用 UDP 端口 **47475**，不需要组播或 IGMP。

- 每台机器每秒广播一次心跳，发往 `255.255.255.255` 和每块网卡各自的广播地址。
- **主节点抽签**：每个节点用一个所有副本共享的种子，对节点 ID 做哈希得到“签”，签最小的是主节点。每台机器各算各的，结果一致，不用协商。
- **转发**：
  - 发送方把“？”单播给主节点。
  - 主节点回一个确认，再单播给所有已知成员，并补发一次广播。
  - 300 ms 内没收到确认（比如主节点刚掉线），发送方就自己广播。
- **成员表**：心跳里带着各自直接听到的成员。所以即使两台机器互相收不到广播，也能通过主节点联通，人数也能算对。
- **主节点故障**：主节点下线约 3.5 秒后，其他人自动改选下一个；这期间的消息靠上面的广播兜底，不会丢。
- **去重与防刷**：
  - 每条消息带来源和随机 ID，不管从哪条路径到达，都只显示一次。
  - 接收方也会对每个来源限流，即使有人改了客户端，也刷不了别人的屏。
- 数据包带一个用共享种子算出的校验标签，不是本程序的包直接丢弃。这不是加密，内容本来也只有一个“？”。
- 与 lolPing 完整版的网络不互通。

## 已知限制

- 管理员权限的窗口在前台时，Windows 不把按键交给普通程序，这时 Alt + ? 不响应。
- 游戏使用独占全屏时，置顶窗口盖不上去，请改用无边框窗口模式。
- 只支持 Windows 10 及以上。

## 构建

需要 Rust 稳定版：

```sh
cd lite
cargo test                 # 网络、限流、落点、动画的测试，任何系统都能跑
cargo build --release      # 无控制台版：target/release/lolping-lite.exe
cargo build                # 调试版：带控制台，实时打印日志
```

- 发布版只把信息级以上的日志写到 `%LOCALAPPDATA%\lolPing Lite\lolping-lite.log`。
- 调试版支持 `--auto-send <毫秒>` 参数，可以不用键盘，定时自动按 Alt + ?，方便多台机器联调。
- `cargo run --release --example preview -- frames out.png` 渲染动画逐帧图，`... -- spots out.png` 渲染落点热力图。
